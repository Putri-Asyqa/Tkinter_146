# Tkinter_146

## Penjelasan Program

Kode ini digunakan untuk membuat aplikasi desktop sederhana menggunakan Python Tkinter untuk memprediksi jurusan kuliah berdasarkan 10 nilai pelajaran.

Pertama, window utama dibuat dengan ukuran 500 × 600 piksel dan latar belakang berwarna abu-abu muda. Agar kode lebih ringkas dan rapi, digunakan perulangan `for` untuk menampilkan 10 kolom input nilai sekaligus.

Ketika tombol "Hasil Prediksi" diklik, fungsi `prediksi_prodi()` akan mengubah label di bagian bawah untuk menampilkan hasil "Prediksi Prodi: Teknologi Informasi".

Terakhir, `root.mainloop()` digunakan agar aplikasi tetap berjalan dan window tetap terbuka selama program digunakan.
